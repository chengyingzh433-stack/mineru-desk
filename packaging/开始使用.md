# MinerU Desk 便携包

版本：0.3.0 · Windows x64 · CPU 环境 · 不含模型

## 打开

1. 把 ZIP **完整解压**到可写目录，例如 `D:\Tools\MinerU-Desk`。不要在压缩软件里直接打开，也不要只拷贝一个 EXE。
2. 双击 **打开 MinerU Desk.vbs**。如果系统禁用 VBS，直接打开 `app\MinerU Desk.exe`。
3. 到“配置与建议”检测电脑；到“模型与服务”下载或导入 Pipeline 模型。下载前先在设置中选好保存路径。
4. 添加文件，选择输出目录，开始转换。PDF 首次使用需要完整模型；DOCX 的文本、表格和图片可以先试。

无需另装 Python、Node.js 或 Codex。推荐 Windows 11 x64；Windows 10 x64 需实际自检，不适用于 ARM 原生版、macOS、Linux。CPU 路径用于兼容普通电脑，长论文速度可能较慢。

这版默认开启“离线使用已有模型”，避免提交 PDF 时意外下载大文件。界面中的“下载模型”仍会联网下载；下载完成后可继续离线转换。云端功能需联网、自己的 Token，并会上传输入文件。

## 文件放在哪里

| 目录 | 内容 |
|---|---|
| app | 前端、任务 API、内置 Node 运行时 |
| runtime | Python、MinerU、固定版本的 CPU 依赖 |
| models | 默认模型目录 |
| cache | 默认临时文件与下载缓存 |
| output | 默认转换结果、自检结果 |
| data | 设置、任务记录、日志、本地连接凭据 |
| examples | 可公开分享的合成样本，不含用户论文 |

后四个工作目录按需生成。应用管理的模型和缓存默认跟随解压目录，具体以设置为准；Windows 自身的系统缓存不在应用控制范围内。清理请使用“存储与清理”，先看清单再确认。原 PDF 不会因转换而被覆盖。

## 让 Codex 操作

将同目录 **给Codex的接入说明.md** 交给 Codex，并告诉它解压路径：

> 按这份说明检查 MinerU Desk，在本机运行自检，告诉我哪些功能已验证、哪些还缺条件；接下来通过 API 帮我转换文件。

不需要再安装 skill。该文档只指导接入，Codex 仍须服从你的实际任务和授权。

## 模型可选，但不能省略验证

当前包不含模型，也不包含下载到一半的文件。下载完整模型后，可供自己离线使用。

要给朋友附带模型：先在原始、未运行过的分享包副本中添加 `models` 文件夹，只放准备分享的完整模型；不要复制 `data`、`cache`、`output`。收件人在“模型与服务”导入相应模型目录，再执行 PDF 自检。模型本身的授权条款也要一并保留。仅看到模型文件夹不代表模型齐全。

## 搬迁、更新与退出

- 关闭窗口不会自动停止任务服务。搬迁整个文件夹或更新前，先结束任务/模型下载/自建服务，关闭窗口，再运行 `Codex.ps1 stop`（命令见接入说明）。
- 整包搬到新位置后，应用会重定位已知的包内路径。自定义的外部目录保持原样；历史缓存指纹会失效一次，旧结果仍保留。仍需检查模型和输出路径。
- 更新请解压新版到新目录。不要覆盖正在运行的程序，也不要在固定的随包 Python 内执行 pip 升级。可在新版本中导入旧模型目录；旧任务数据先保留，不自动迁移。
- 分享请发原始发布 ZIP。你使用过的文件夹可能含论文、历史、日志或密钥，不宜直接重新压缩发人。

## 如果打不开

先完整解压，检查目标磁盘空间以及文件是否被安全软件隔离。此包未做商业代码签名，Windows 可能提示未知发布者；核对来源和 ZIP 校验值后自行决定，不要关闭系统安全防护。

运行 Codex 自检能检查 Python、PyTorch、内存、显卡与磁盘，但不能预先保证每台机器和每份论文都成功。缺 DLL、模型不完整、内存不足和不支持的 GPU 会有不同处理方式；不要反复重装整个环境。

本地硬件要求请看界面中的官方参考链接。CPU 使用 Pipeline，不需要独立显存；本包的 CPU PyTorch 不会自动变成 CUDA 版。有 NVIDIA 显卡也需另建匹配的 GPU 环境后实测。

第三方版本与许可见 `第三方组件说明.md`、`licenses` 和 `dependency-inventory.json`。
