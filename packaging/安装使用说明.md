# MinerU Desk 0.3.2 安装使用说明

Windows x64 · 内置 MinerU、Python 与 CPU 运行依赖 · 不含 Pipeline/VLM 大模型

## 安装

双击 `MinerU-Desk-Setup-0.3.2-x64.exe`，按向导选择安装目录，再完成安装。桌面和开始菜单会出现笔和信纸图标的 MinerU Desk。无需另装 Python、Node.js 或 Codex。模型可在客户端选择保存位置后一键下载。

## 更新和卸载

“应用设置 / 更新 → 版本与维护”提供检查更新、下载进度和确认安装。检查只读取 GitHub 正式发布信息，不自动下载；下载完成并校验 SHA-256 后，点击“安装更新并重启”。程序使用原安装目录覆盖安装，保留模型、论文、结果、Token 和历史。

从 0.3.1 首次升级，请下载此安装包覆盖安装一次，无需先卸载。先保存编辑并关闭客户端；后台仍在运行时，在旧安装目录执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Codex.ps1 stop`，再运行安装程序。命令只会关闭没有任务和服务的后台。

“卸载 MinerU 与桌面程序…”会关闭空闲后台并打开卸载确认窗口，删除桌面程序和随包 MinerU、Python、CPU 依赖。模型、原始文档、结果、设置、任务记录以及单独安装的其他 MinerU 环境保留。也可从开始菜单或 Windows 应用列表卸载。

更新包保存在所选缓存目录的 `updates` 子目录；取消或失败会清理本次下载残片。安装结束后清理已校验的下载 EXE。尚未安装的完整更新包会暂时保留。

官方 Token 可从云端转换选项的“获取官方 Token ↗”打开申请页。登录创建后，回到“应用设置 / 更新 → 官方云端”粘贴并点击“保存 Token”。

安装器未做商业签名。请从可信来源接收并核对 SHA-256；遇到安全提示自行核验来源，不要关闭系统防护。本版按当前用户安装，不自动申请管理员权限，请选择自己有写入权限的目录。

例如安装到 `D:\Tools\MinerU Desk`，默认数据放在旁边的 `D:\Tools\MinerU-Desk-Data`：

| 子目录 | 用途 |
|---|---|
| data | 配置、任务记录、连接凭据和报告 |
| models | 下载或导入的模型；安装包不附带大模型 |
| cache | 临时文件、下载缓存 |
| output | 转换结果 |

数据目录不在程序安装目录内，升级/卸载程序不会主动删除它。在应用“存储与清理”中可以分别选择后续模型下载、缓存和结果地址；更改地址不会自动搬迁已有模型。要迁移已有模型，停止转换后复制完整目录，在“模型与服务”导入新地址，确认转换可用后再自行处理旧副本。安装版不允许把这些地址设进安装目录。不要自行把个人论文放进安装目录。

选择 D 盘安装目录后，后续下载的模型也默认放在 D 盘。程序约需 2.6 GiB，安装解压还需要临时空间，建议预留至少 6 GiB；下载模型另需数 GB。重装不修改外部模型。

## 首次使用

1. 打开“配置与建议”检测电脑。此包采用 CPU PyTorch；CPU 使用 Pipeline。显卡支持与否不能只凭名称判断。
2. 在“模型与服务”选择模型保存地址，然后下载 Pipeline；或直接导入原有的完整模型目录。已下载模型不必重下。已有配置不被覆盖，旧便携版任务记录不自动搬迁。
3. 添加 PDF、Word 等文件，选择转换方式与输出路径。默认离线使用已有模型；下载按钮仍可联网下载模型。
4. 查看结果。保留 Markdown 配套图片目录，关键术语、公式、表格对照原 PDF 检查。完成不等于没有漏字。

云端使用自己的 Token，需要联网且会上传输入文件。CPU 本地转换不需要云端 Token。部分系统可能缺少 Microsoft Visual C++ 运行库，具体处理见 Codex 接入说明。

## 清理任务记录

在“任务记录”勾选任务，点击“清理所选”：

- **仅移出前端列表**：结果和后台记录保留；切换“已移出列表”仍可搜索、查看、恢复，Codex 也能查询。
- **删除记录及资源**：先列出路径和体积，再确认删除转换结果、图片、手工编辑和本次临时资源。不清理共享模型。
- **另删原始 PDF**：危险选项默认不选；逐项勾选原文，核对清单，再输入 `删除原始PDF`。属于永久删除，应用不能恢复。其他任务仍使用的原文、共享结果和目录链接会阻止删除。

进行中、排队或待继续任务不能清理。文件或任务在预览后有变化，会要求重新预览。“清理报告”提供操作回执；部分删除失败时保留任务记录，不假报全部成功。

## 给 Codex 使用

把安装目录里的 `给Codex的接入说明.md` 交给 Codex，告诉它：“按说明找到本机安装，检测配置并做自检，再通过 API 操作。”不用另外安装 skill。软件也提供本地接口，桌面端和 Codex 共用任务记录。

## 升级、卸载

先保存 Markdown 编辑，结束转换/下载/自建服务，关闭客户端和后台服务，再运行新版安装器。不要手动修改随包 Python 的依赖版本。

卸载仅处理程序；外部数据、模型、论文与结果需要用户另外管理，不自动清空。旧便携版仍留在原位置，不会被新安装器自动删除或迁移。

0.3.1 修复了 Windows 中文路径下 FastText 语言识别模型加载失败的问题。未移动用户模型、未重下模型、未改变论文内容。第三方许可和修改说明随安装保留。
